# SECAF v1.0 — Example Cybersecurity Assessment

## About This Example

This is a fictional example created to demonstrate how the SECAF framework can be used.

It does not represent an assessment of a real customer, organisation or energy installation.

The example assumes a small connected solar energy system with an inverter, battery storage, Wi-Fi connection, mobile monitoring application and cloud platform.

---

## Example System

| Component | Example |
|---|---|
| Energy System | Connected solar and battery installation |
| Inverter | Wi-Fi-enabled hybrid inverter |
| Battery | Lithium battery storage system |
| Network | Local Wi-Fi network |
| User Access | Mobile monitoring application |
| Remote Service | Cloud monitoring platform |

---

## Example Finding F-01

**Checklist Reference:** AC-01

**Finding:**  
Default administrator credentials have not been changed.

**Observation:**  
For this fictional example, the system is assumed to still use the default administrator credentials provided during initial setup.

**Likelihood:** 5 — Very Likely

**Impact:** 5 — Severe

**Risk Score:** 25

**Risk Level:** Critical

**Recommended Action:**  
Replace the default administrator credentials with a strong, unique password. Enable multi-factor authentication if the platform supports it.

**Status:** Open

---

## Why This Finding Matters

Default credentials can increase the risk of unauthorised access when they are known, easily discovered or shared across devices.

Changing default credentials is therefore an important security step when setting up a connected energy system.

---

## Important Note

The scores used in this example are for demonstration purposes only.

A real SECAF assessment should assign likelihood and impact based on the actual system, its configuration, available security controls and the environment in which it operates.
